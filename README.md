# Xlntbi - Sarinay Dávid

xlntbi.hu

Ezt a projektet másodszor a szokásos lavabonnal is szerint. Lesz majd rajta később online fizetés, meg bankkártyás fizetés, készítsd rá fel.

Ezek csak online termékek, tehát szállítási cím meg ilyesmi nincs, számlázási cím van. Majd rajta egy komplexebb kalkulátor.

Minden médiatartalmat meg ilyesmit töltsd fel, amennyire lehet, egy per egy kopit csünyálni belőle. Kérlek! Nagyon alaposan, nagyon szuperül, nagyon jó.
